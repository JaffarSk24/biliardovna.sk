# Инструкция по подключению партнеров к Telegram-боту

Эта инструкция поможет вам подключить новых партнеров (администраторов) к боту для получения уведомлений о бронированиях и управления ими.

## 1. Где лежат логи?

Логи всех запросов к боту записываются в файл:
`logs/telegram.log`
(от корня проекта: `public_html/logs/telegram.log`)

> **Важно:** Если этого файла нет или он пуст, значит, Telegram **не отправляет** запросы на ваш сайт. Скорее всего, не настроен Webhook.

---

## 2. Как узнать Chat ID партнера?

Поскольку бот игнорирует сообщения от "неизвестных" пользователей (для безопасности), партнер не может просто написать боту `/start` и получить ответ, пока вы его не добавите.

**Способ А (Самый простой):**

1. Попросите партнера найти в Telegram бота **@userinfobot**.
2. Пусть он нажмет `/start` или напишет любое сообщение этому стороннему боту.
3. Бот пришлет в ответ `Id: 123456789`.
4. Это число (`123456789`) и есть **Chat ID**.

**Способ Б (Если Webhook работает и логи пишутся):**

1. Партнер пишет любое сообщение вашему боту.
2. Вы открываете файл `logs/telegram.log`.
3. Ищете там последнее сообщение. Оно будет в формате JSON.
4. Ищете внутри структуру: `"chat":{"id":123456789,...`.
5. Копируете `id`.

---

## 3. Как добавить партнера?

1. Откройте файл `.env` в корне сайта.
2. Найдите строку `TELEGRAM_ALLOWED_CHATS`.
3. Добавьте полученный Chat ID через запятую (без пробелов).

**Пример:**
Было:

```env
TELEGRAM_ALLOWED_CHATS=11111111,22222222
```

Стало (добавили партнера с ID 33333333):

```env
TELEGRAM_ALLOWED_CHATS=11111111,22222222,33333333
```

4. Сохраните файл. Изменения вступают в силу мгновенно.

---

## 4. Проверка работы

1. После добавления ID, партнер может написать боту команду `/start` или `?` (для поиска брони).
2. Если всё настроено верно, бот ответит.
3. Теперь этот партнер будет получать уведомления о новых бронированиях.

---

## 5. Если логи не пишутся (Настройка Webhook)

Если партнер пишет боту, а файл `logs/telegram.log` не появляется, значит Telegram не знает, куда слать данные. Нужно зарегистрировать Webhook.

Вам нужно открыть в браузере специальную ссылку **заменив ТОКЕН и ДОМЕН**:

```
https://api.telegram.org/bot<ВАШ_ТОКЕН>/setWebhook?url=https://<ВАШ_ДОМЕН>/webhook/telegram
```

**Пример:**
Если токен `123:ABC` и домен `biliardovna.sk`:
`https://api.telegram.org/bot123:ABC/setWebhook?url=https://biliardovna.sk/webhook/telegram`

При успешной установке вы увидите: `{"ok":true,"result":true,"description":"Webhook was set"}`.
